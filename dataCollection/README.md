This folder contains the python scripts that were written to scrape the data collected in the data folder. 
One sript is responsible for collecting the quotes off of the goodreads site from the top 100 downloaded 
books in the past 30 days. This script creates one CSV file. The other collects the surrounding context 
from the given quote set off of Project gutenburg and creates a CSV file with the quotes with context and 
another with the quotes where context could not be found in teh version of the book freely available.
